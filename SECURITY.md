# Security policy

## Supported versions

The project is pre-release. Security fixes currently target the default branch
and the newest published prerelease, if any.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is enabled for this
repository. If it is not available, contact a repository maintainer privately
through the contact method on their GitHub profile and ask for a secure channel.

Do not open a public issue containing:

- credentials, OAuth codes, cookies, or private keys;
- private player audio, transcripts, saves, or guide memory;
- a working exploit against a deployed instance; or
- sensitive provider account or billing information.

Include the affected revision, impact, minimum reproduction, and any evidence
that game state, private data, or provider spending changed. Redact secrets and
personal data. Maintainers will acknowledge a complete private report, assess
containment, and coordinate disclosure before publishing details.

For an exposed credential, revoke it with the issuing provider immediately; do
not wait for a code fix.
