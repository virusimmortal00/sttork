# License records

The repository root `LICENSE` applies only to project-owned work unless a file
states otherwise. Third-party license texts and notices belong here and must be
linked from a machine-readable record under `provenance/`.

`dork/` preserves the candidate interpreter's MIT license and ancestry notice.
`zork1/` preserves the Microsoft MIT license accompanying the imported Release
119 story. Their exact source identities, local hashes, conditions, and
trademark exclusions are recorded under `provenance/records/`.
