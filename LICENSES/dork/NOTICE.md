## JSZM — the interpreter's ancestry

`src/zmachine/` began as a port of **JSZM v2.0.2**, a Z-machine implementation
in JavaScript/ES6 by **zzo38 (Aaron Black)**, rewritten for TypeScript and
`async`/`await`.

JSZM is in the public domain. The author's statement, from the release thread:

> it is made at the request of someone else. It is in the public domain.

- Upstream: <http://zzo38computer.org/jszm/jszm.js>
- GitHub snapshot (taken with the author's permission):
  <https://github.com/DLehenbauer/jszm>
- Release thread: <https://intfiction.org/t/jszm-javascript-z-machine-v2-0-3/9693>

No attribution is legally required for public-domain work. This notice exists
because the credit is deserved.

## Zork I — the bundled story file

`vendor/zork1/zork1.zip` is the compiled Zork I story file, Release 119 / serial
number 880429. In November 2025 Microsoft, Xbox and Activision released the
source and compiled builds of Zork I, II and III under the MIT License.

- Copyright (c) 2025 Microsoft. Full text: [vendor/zork1/LICENSE](vendor/zork1/LICENSE)
- Source: <https://github.com/historicalsource/zork1>
- Announcement:
  <https://opensource.microsoft.com/blog/2025/11/20/preserving-code-that-shaped-generations-zork-i-ii-and-iii-go-open-source/>

`zork1.script.expected.txt` is a reference transcript generated by running that
story file under `dfrotz`, so it is covered by the same MIT grant.
